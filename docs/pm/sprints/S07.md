## Retrospective

**What went right:** the resolver seam from v0 made T1 wiring a three-line
change; redaction-at-publish gave whole-pipeline coverage for one wrapper;
the canary e2e doubles as the first test that exercises audit + SSE + REST
in a single pass.

**What to watch:** the e2e initially "hung" — actually the P2.M1 default
posture confirm-pausing the fixture tool_call for its full 300s timeout;
pre-policy suites must keep opting out explicitly. `costs.ndjson` is
written from the scheduler's onEvent side-channel, upstream of the bus —
safe today because cost payloads are numeric-only, but it should migrate
to a bus subscriber before anything string-valued ever rides cost events.
D11 harness drift is exactly what P2.M7 managed binaries pin away.
