## Retrospective

**What went right:** scope discipline held even as scope *grew* —
every extension (multi-account slots, OpenCode, the whole rest of P1)
was an explicit Kabeer decision, never an assumed one, and each got its
own plan doc + ROADMAP entry rather than silent expansion. TDD-first
execution across 6 new packages (memory, scheduler, api, sdk, cli, ade)
kept the workspace suite green throughout — 211 tests, zero regressions,
verified twice per milestone for flake. The pre-merge clean-clone
verification (fresh `git clone` → `frozen-lockfile install` → `build`)
caught a real missing-dependency bug that local iteration had masked.

**What to watch next sprint:** local development never exercises a truly
frozen lockfile the way CI does — worth running `pnpm install
--frozen-lockfile` locally before every PR, not just before a tag.
The STOP kill-switch E2E test needed two rounds of race-condition
fixes (racing wall-clock delays against an in-process scheduler) before
it was deterministic — prefer waiting for an *observed state transition*
over a fixed delay when testing anything async in this codebase.
