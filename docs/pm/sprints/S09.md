## Retrospective

**What went right:** the dependency-inverted `PtyBridge` seam kept
`@aeos/api` free of a runner dependency while aeosd supplies the real
supervisor-backed bridge — boundaries stayed clean under depcruise without
contortions. Additive protocol messages avoided a version bump entirely.
The Playwright T5 flow (park → grant allow mid-session → attach) doubles as
proof that the policy gate re-evaluates per request, which is the behavior
an operator would actually want.

**What went wrong (and was caught):** three separate debugging sessions,
all instructive — an evaluation-order bug capturing a tmpdir before it was
created (load-dependent PTY flake), the @fastify/websocket v11 raw-socket
handler signature (swallowed TypeError left connections open), and vitest's
default 5s timeout masquerading as logic failures. The forensics habit
(pty.log, stage logging, plain-node repro outside vitest) found each root
cause in minutes.

**What to watch:** the takeover shell runs a minimal env by design — users
expecting their full login environment will notice; if that friction
matters, a documented opt-in env expansion beats silently leaking daemon
secrets. The co-edit guard ships unwired (see ADR-009) — activation is one
wiring change once real worktrees exist. And P2.M6 needs the Codex CLI
before its golden fixtures can be recorded.
