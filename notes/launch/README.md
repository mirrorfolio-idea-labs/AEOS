# Launch kit (P5.M5.T3), drafts for Kabeer

These are drafts only. Publishing them is Kabeer's call and Kabeer's
voice. Every claim in them is backed by something tested in CI; the
evidence is listed at the bottom of each file. Check that list again
before posting.

| File | Where it goes |
|---|---|
| `blog-post.md` | The announcement post (company blog, dev.to, or similar) |
| `show-hn.md` | Hacker News (Show HN) |
| `social.md` | An X/Bluesky thread, a LinkedIn post, and Reddit (r/programming, r/ClaudeAI, r/LocalLLaMA) |
| `awesome-lists.md` | awesome-list PRs to open after launch |

**Order on launch day:**
1. Tag `v1.0.0`, and wait for the release workflow to go green.
2. The docs site is live.
3. Publish the blog post.
4. Post Show HN, linking the repo rather than the blog.
5. Post the social thread.
6. Post to Reddit, spaced a few hours apart.
7. Open the awesome-list PRs the next day.
